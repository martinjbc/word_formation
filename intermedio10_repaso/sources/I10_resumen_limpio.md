# I10 - Resumen limpio de anotaciones

## 1. Temas principales para examen

Prioridad alta:

- Modal verbs: `must`, `have to`, `mustn't`, `don't have to`, `needn't`, `should`, `can`, `may`, `might`, `could`.
- Past modals of deduction: `must have`, `can't have`, `might/could/may have` + past participle.
- Verb/adjective + preposition: `accuse of`, `blame for`, `insist on`, `expose to`, `interested in`, `good at`, `responsible for`.
- Word formation y prefixes: `self-`, `bi-`, `inter-`, `semi-`, `mono-`, `un-`, `in-/im-/il-/ir-`, `dis-`, `mis-`.
- Participle clauses: `-ing`, past participle, `having + V3`, `having been + V3`.
- Relative clauses: defining clauses con `who`, `which`, `that`, `whose`, `where`.
- Speaking/reviews: describir impresiones positivas y negativas.

## 2. Modal verbs en presente

| Uso | Estructura | Significado |
|---|---|---|
| Obligacion fuerte | `must` / `have to` | tener que |
| Prohibicion | `mustn't` / `can't` | no se permite |
| No es necesario | `don't have to` / `don't need to` / `needn't` | no tienes que |
| Consejo | `should` / `ought to` | deberias |
| Permiso/habilidad | `can` / `may` | poder |
| Posibilidad | `could` / `might` / `may` | podria / tal vez |

Error clave:

- `You mustn't go` = esta prohibido ir.
- `You don't have to go` = no es necesario ir.

## 3. Past modals of deduction

| Idea | Estructura | Ejemplo |
|---|---|---|
| Certeza sobre el pasado | `must have + V3` | `He must have left.` |
| Seguro que no paso | `can't/couldn't have + V3` | `She can't have forgotten.` |
| Posibilidad en el pasado | `might/could/may have + V3` | `They might have missed the bus.` |

Traduccion practica:

- `must have seen` = seguramente vio / debe haber visto.
- `can't have known` = no puede haber sabido.
- `might have dropped` = puede que haya dejado caer.

## 5. Word formation y prefixes

| Prefijo/sufijo | Idea | Ejemplos |
|---|---|---|
| `self-` | uno mismo | `self-awareness`, `self-interest`, `self-centred` |
| `bi-` | dos | `bilingual`, `biannual` |
| `inter-` | entre | `interconnect`, `international`, `intercontinental` |
| `semi-` | medio/parcial | `semi-retired`, `semicircle`, `semiskilled` |
| `mono-` | uno | `monolingual`, `monotone` |
| `un-` | negativo | `unfair`, `unusual` |
| `in-/im-/il-/ir-` | negativo | `impossible`, `illegal`, `irregular` |
| `dis-` | opuesto | `disagree`, `dishonest` |
| `mis-` | mal/incorrectamente | `misunderstand`, `mislead` |
| `-ly` | adverbio | `accidentally`, `kindly`, `technologically` |
| `-cy` | sustantivo | `privacy`, `accuracy`, `fluency` |
| `-able/-ible` | adjetivo | `preferable`, `responsible`, `possible` |
| `-ic/-ical` | adjetivo | `sympathetic`, `critical`, `practical` |

Familias importantes:

- `prefer` -> `preference` -> `preferable` -> `preferably`.
- `enthusiasm` -> `enthusiastic` -> `enthusiastically`.
- `private` -> `privacy` -> `privately`.
- `criticise` -> `criticism` -> `critical` -> `critically`.

## 6. Participle clauses

| Forma | Uso | Ejemplo |
|---|---|---|
| `-ing` | accion activa | `Hearing a noise, Jason got up.` |
| Past participle | pasivo | `Born in Peru, he speaks Spanish.` |
| `Having + V3` | accion anterior activa | `Having finished my work, I went home.` |
| `Having been + V3` | accion anterior pasiva | `Having been invited, she smiled.` |

Atajos:

- `who is standing` -> `standing`.
- `who was born` -> `born`.
- `after she had studied` -> `having studied`.
- `after he had been told` -> `having been told`.

## 7. Relative clauses

| Pronombre | Uso |
|---|---|
| `who` | persona |
| `which` | cosa |
| `that` | persona o cosa en defining clauses |
| `whose` | posesion |
| `where` | lugar |

Defining relative clause: la informacion es necesaria para identificar de que persona/cosa hablamos.

Ejemplos:

- `The book that you gave me belongs to Sarah.`
- `The car that she bought last week is red.`

## 10. Speaking: agreeing/disagreeing

Agreeing:

- `I'm with you there.` = Estoy de acuerdo contigo.
- `I completely agree.` = Estoy completamente de acuerdo.
- `That's just what I was thinking.` = Eso es justo lo que pensaba.

Disagreeing:

- `That's not really how I see it.` = No lo veo asi.
- `You can't be serious!` = No puedes hablar en serio.
- `Come off it!` = Vamos, no exageres.
- `I don't think that anyone would disagree with...` = No creo que alguien no este de acuerdo con...

## 11. Speaking/reviews: impressions

Positive:

- `It's stunning / magical / breathtaking / fascinating.`
- `It's really impressive / inspiring.`
- `What I particularly liked/loved was...`
- `I like the way...`
- `For me, the highlight was...`
- `It was well worth + verb-ing.`

Negative:

- `I wasn't that impressed by...`
- `I found it a bit dull / weird / disturbing / disappointing.`
- `I didn't see the point of it.`
- `It's too... for my liking.`
- `It didn't live up to my expectations.`

## 15. Frases que conviene memorizar

- `mustn't` = prohibido; `don't have to` = no es necesario.
- `modal + have + V3` para deduccion en pasado.
- Aprende `verbo/adjetivo + preposicion` como una sola unidad.
- `participle clauses`: activo `-ing`, pasivo `V3`, anterior `having + V3`.
- `It was well worth + -ing`.
- `I didn't see the point of it.`
- `It didn't live up to my expectations.`
- `What I particularly liked was...`
- `For me, the highlight was...`
